# 🔥 Fuego & Brasa - Restaurante Parrillero

¡Bienvenido al repositorio de **Fuego & Brasa**! Este es un sitio web moderno, elegante y completamente responsivo desarrollado para un restaurante de alta cocina parrillera y cortes premium. 

El proyecto está diseñado desde cero enfocándose en la experiencia del usuario, con una navegación fluida y una estética visual que rinde homenaje al arte de la cocina a las brasas.

---

## 📱 Características del Proyecto

* **Diseño Completamente Responsivo:** Adaptado meticulosamente para computadoras, tablets y teléfonos móviles (Media Queries).
* **Sección de Carta Interactiva:** Un menú organizado por categorías (Entradas, Cortes, Guarniciones, Postres y Bebidas) optimizado para lectura táctil.
* **Estructura Semántica:** HTML5 limpio y estructurado de forma profesional para un mejor SEO.
* **Estilos Personalizados:** CSS3 puro, utilizando sistemas de distribución modernos (Flexbox y CSS Grid).

---

## 🗂️ Estructura del Sitio Web

El sitio está compuesto por las siguientes páginas:

1.  **Home (`index.html`):** Bienvenida, especialidades y llamada a la acción para reservas.
2.  **Nosotros (`nosotros.html`):** Historia del restaurante, misión, visión, valores y presentación del equipo de maestros parrilleros junto con la ubicación (Mapa).
3.  **Carta (`carta.html`):** El menú completo con descripciones detalladas de los platos optimizadas para dispositivos móviles.
4.  **Contacto (`contacto.html`):** Formulario para reservas y consultas.
5.  **Blog (`blog.html`):** Espacio para artículos y secretos sobre el mundo del asado.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** - Estructuración semántica del contenido.
* **CSS3** - Estilos personalizados, Flexbox, Grid Layout y Media Queries para la responsividad.
* **FontAwesome** - Iconografía del sitio (redes sociales, iconos de navegación).
* **Google Fonts** - Tipografías seleccionadas para transmitir la identidad del restaurante.
